2Statements

Broker statement files

For DeGiro, Trade Republic and Trading 212 you can upload the full statement from the broker. One file covers every trade, dividend and interest payment. Upload a newer one whenever you want to update.
  1. In DeGiro, open Activity → Account statement.
  2. Choose all dates since you opened the account.
  3. Download it as PDF, or export it as CSV.
Either file works. A PDF is converted here, and every trade is checked against its booked amount.
  1. In the Trade Republic app, open Profile → Account statements.
  2. Download the account statement PDF from the day you opened the account, or the transaction export (CSV).
One file covers trades, dividends and interest. Every PDF row is checked against the running balance.
Dividends and interest file (JSON, rarely needed)
Filled in automatically from the transaction export above. Only needed for data you typed up yourself; the format is in income_trade_republic.sample.json.
Best: connect each Trading 212 account (Invest, Stocks ISA) with a read-only key under Add an account. Keys can also be set on the server: T212_INVEST_API_KEY + T212_INVEST_API_SECRET and T212_ISA_API_KEY + T212_ISA_API_SECRET (or one T212_API_KEY + T212_API_SECRET). Accounts with "ISA" in the name count as tax-free.
No key, for example for a closed account? Upload its statement (in EUR):
  1. In Trading 212, open Menu → History → Export / Activity statement.
  2. Pick the full period the account was open and download the PDF.
  3. A History CSV export (12 months at most) uploaded after it is added on.
Don't upload a statement for an account that also has a key: it would count twice.

This host wipes its disk on every restart. To keep your changes, give the app a private place to save them: create a private GitHub repository, make a fine-grained token with Contents: read & write on that repository only, and add two settings on the host: GITHUB_TOKEN (the token) and GITHUB_REPO (your-name/your-repository). Every change is then saved there, encrypted. Step by step: SETUP.md.
