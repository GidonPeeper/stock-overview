Free hosting wipes its disk on every restart. With a GitHub token set, every edit here is encrypted into the vault and committed to a data-sync branch automatically — so balances and uploads survive restarts and deploys. Setup: GitHub → Settings → Developer settings → Fine-grained tokens → new token with Contents: read & write on this repo only → add it as env var GITHUB_TOKEN on the host.

DeGiro — account statement (PDF or CSV)

DeGiro → Activity → Account statement → all dates since account opening → download as PDF or export as CSV. Either file works; the PDF is converted here and every trade is checked against its booked amount.

Trade Republic — account statement (PDF) or transaction export (CSV)

Trade Republic app → Profile → Account statements: the account statement PDF from the day you opened the account, or the transaction export (CSV). One file covers everything: trades, dividends and interest are all read from it, and every PDF row is checked against the running balance.

Trade Republic — dividends & interest (JSON, optional)

Filled automatically from the transaction export above; only needed for hand-transcribed data — format in income_trade_republic.sample.json.

Trading 212 — API accounts or activity statement (PDF)

Live via the read-only API. Each Trading 212 account (Invest, Stocks ISA) has its own key pair: set T212_INVEST_API_KEY + T212_INVEST_API_SECRET and T212_ISA_API_KEY + T212_ISA_API_SECRET on the host (or one plain T212_API_KEY + T212_API_SECRET). Accounts with "ISA" in the name are treated as tax-free.
For an account without a key, such as a closed EU account, upload its statement (EUR): Trading 212 → Menu → History → Export / Activity statement (PDF, full period the account was open). It is shown next to your live accounts, so its trades, dividends and interest stay in your history. A History CSV export (12 months at most) uploaded after it is added on. Don't upload a statement for an account that also has a key: it would count twice.

Bank, savings & retirement accounts

Cash, savings and pension pots — 401(k), IRA, pensioen, lijfrente. Type in a balance here and edit it in seconds. Banks in the EU (Rabobank, ING, ABN AMRO, bunq, EU Revolut…) can also update on their own: add them above under Add an account → Bank link.
